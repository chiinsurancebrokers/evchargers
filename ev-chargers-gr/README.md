# ⚡ Φορτιστές Η/Ο — Δημόσιο Δίκτυο Ελλάδας

Διαδραστικός χάρτης των **δημόσια προσβάσιμων** σταθμών φόρτισης ηλεκτρικών οχημάτων
στην Ελλάδα, με **φίλτρα ισχύος (50 kW / 120 kW)** και **σχεδιασμό διαδρομής** που
εντοπίζει τους συμβατούς φορτιστές κατά μήκος της.

Τα δεδομένα προέρχονται από το **Μ.Υ.Φ.Α.Η.** (Μητρώο Υποδομών Φόρτισης Α.Η., Υπουργείο
Υποδομών & Μεταφορών) και είναι ελεύθερα διαθέσιμα στη σελίδα
[Διάθεση Δημοσίων Δεδομένων](https://electrokinisi.yme.gov.gr/public/HelpMyfah/PublicData/).

---

## Τι κάνει

- **Χάρτης** με όλους τους σταθμούς, χρωματισμένους ανά ισχύ:
  - 🟢 **50 kW** ταχυφορτιστές (50–119 kW)
  - 🔵 **120 kW** υπερ-ταχυφορτιστές (≥120 kW)
  - ⚪ Αργοί / AC (<50 kW) — προαιρετικά
- **Κατάσταση σε πραγματικό χρόνο** (διαθέσιμος / σε φόρτιση / εκτός), από τα δυναμικά
  δεδομένα που ανανεώνονται κάθε ~10 λεπτά.
- **Σχεδιασμός διαδρομής**: δίνεις αφετηρία & προορισμό, υπολογίζεται η διαδρομή και
  εμφανίζονται —με τη σειρά— οι φορτιστές που πληρούν τα κριτήριά σου εντός Χ km από αυτήν.
- Φίλτρο «μόνο διαθέσιμοι αυτή τη στιγμή».

## Πώς λειτουργεί

```
Μ.Υ.Φ.Α.Η. (zipped JSON, OCPI 2.2)
        │  download + unzip + parse (server.js)
        ▼
  cache στη μνήμη  ──►  GET /api/chargers  ──►  Leaflet χάρτης (public/)
        ▲
  ανανέωση: στατικά κάθε 6h, δυναμικά κάθε 10'
```

Ο Node server κατεβάζει τα δύο δημόσια αρχεία, τα αποσυμπιέζει, υπολογίζει την ισχύ
κάθε connector (από το `max_electric_power` του OCPI, με fallback `V × A`), συγχωνεύει
τις τρέχουσες καταστάσεις και τα σερβίρει ως καθαρό, μικρό JSON. Έτσι ο browser δεν
χρειάζεται να κατεβάζει/αποσυμπιέζει τίποτα και αποφεύγονται τα CORS.

## Deploy στο Railway

### Α) Μέσω GitHub (προτεινόμενο)

1. Ανέβασε αυτόν τον φάκελο σε ένα GitHub repo.
2. Στο [railway.app](https://railway.app): **New Project → Deploy from GitHub repo** και διάλεξέ το.
3. Το Railway αναγνωρίζει αυτόματα Node (Nixpacks), τρέχει `npm install` και `npm start`.
4. **Settings → Networking → Generate Domain** για δημόσιο URL. Τέλος.

Δεν χρειάζεται καμία ρύθμιση: ο server ακούει στο `process.env.PORT` που δίνει το Railway.

### Β) Μέσω Railway CLI

```bash
npm i -g @railway/cli
railway login
railway init
railway up
railway domain   # δημιουργεί δημόσιο URL
```

### Μεταβλητές περιβάλλοντος (προαιρετικές)

| Μεταβλητή            | Default                                   | Περιγραφή                          |
| -------------------- | ----------------------------------------- | ---------------------------------- |
| `PORT`               | δίνεται από Railway                        | Θύρα του server                    |
| `MYFAH_STATIC_URL`   | …/GR.IDRO.static.data.latest.json.zip     | URL στατικών δεδομένων             |
| `MYFAH_DYNAMIC_URL`  | …/GR.IDRO.dynamic.data.latest.json.zip    | URL δυναμικών δεδομένων            |
| `MYFAH_API_URL`      | — (κενό)                                   | *(προαιρετικό)* OCPI endpoint `GET /locations` |
| `MYFAH_API_TOKEN`    | — (κενό)                                   | *(προαιρετικό)* το παραγωγικό Token |
| `ANTHROPIC_API_KEY`  | — (κενό)                                   | *(προαιρετικό)* ενεργοποιεί τη «δεύτερη γνώμη» & τα αξιοθέατα |
| `ANTHROPIC_MODEL`    | `claude-sonnet-4-6`                        | *(προαιρετικό)* μοντέλο Claude |
| `LOCATIONIQ_KEY`     | — (κενό)                                   | *(προαιρετικό)* geocoding/routing μέσω LocationIQ· αλλιώς Nominatim/OSRM |

### Προαιρετικά: άντληση από το OCPI API αντί για τα zip

Αν είσαι εγγεγραμμένος **Φ.Ε.Υ.Φ.Η.Ο.** και έχεις **παραγωγικό** token + endpoint, όρισε
και τις δύο μεταβλητές `MYFAH_API_URL` και `MYFAH_API_TOKEN`. Τότε ο server τραβάει live
από το OCPI `GET /locations` (στέλνει `Authorization: Token <…>`) και ανανεώνει κάθε 10′·
οι καταστάσεις των φορτιστών έρχονται μέσα στην ίδια απάντηση.

> ⚠️ Το **δοκιμαστικό** endpoint `https://dev.e-research.gr/myfah/ocpi/2.2/locations/` με το
> test token επιστρέφει **μόνο δοκιμαστικά** δεδομένα (έναν σταθμό), όχι το εθνικό δίκτυο.
> Για πραγματικά δεδομένα **χωρίς** token, άφησε τις μεταβλητές κενές — η εφαρμογή θα
> χρησιμοποιήσει τα δημόσια zip (η προεπιλογή).

## Σχεδιασμός ταξιδιού με όχημα

Στην ενότητα «Όχημα & μπαταρία» διαλέγεις μοντέλο (ή προσαρμόζεις μπαταρία/κατανάλωση),
βάζεις την **εκκίνηση μπαταρίας (%)** και το **όριο φόρτισης (π.χ. 20%)**. Μετά τον
σχεδιασμό διαδρομής εμφανίζεται:

- **πόσα km μέχρι η μπαταρία να φτάσει το όριο** (σημειωμένο και πάνω στον χάρτη),
- ο **βέλτιστος/κοντινότερος φορτιστής** πριν από εκείνο το σημείο και πλήρης **αλυσίδα στάσεων**
  μέχρι τον προορισμό (με % άφιξης σε κάθε στάση),
- **κατανάλωση αυτοκινητόδρομου**: η κατανάλωση προσαυξάνεται αυτόματα ανάλογα με τη μέση
  ταχύτητα της διαδρομής (έως +45%),
- **πραγματική οδική παράκαμψη** για κάθε στάση (δεύτερη κλήση OSRM, μετ' επιστροφής).

### Δεύτερη γνώμη με Claude

Αν οριστεί `ANTHROPIC_API_KEY`, εμφανίζεται κουμπί **«Δεύτερη γνώμη με Claude»** που στέλνει
το πλάνο στο Claude API και επιστρέφει σύντομη κρίση + εναλλακτική στρατηγική στάσεων.

> 🔒 Το κλειδί μένει **μόνο στον server** (στο endpoint `POST /api/second-opinion`) και
> **ποτέ** δεν εκτίθεται στο frontend. Αν λείπει, το κουμπί επιστρέφει ευγενικό μήνυμα ότι
> η λειτουργία είναι ανενεργή. Πρόσθετη μεταβλητή για προχωρημένους: `ANTHROPIC_BASE_URL`.

### Αξιοθέατα & σημεία στη διαδρομή (με Claude)

Μετά τον σχεδιασμό διαδρομής, το κουμπί **«🏛️ Αξιοθέατα & σημεία στη διαδρομή»** δειγματοληπτεί
τα πραγματικά τοπωνύμια κατά μήκος της (reverse geocoding) και ζητά από το Claude προτάσεις σε
4 κατηγορίες — **αρχαιολογικοί/πολιτιστικοί χώροι, φαγητό, διαμονή, δραστηριότητες** — οργανωμένες
ανά περιοχή. Κλικ σε ένα σημείο το εντοπίζει στον χάρτη. Χρησιμοποιεί το ίδιο `ANTHROPIC_API_KEY`
(endpoint `POST /api/route-pois`).

### Κινητό

Σε οθόνες κινητού το πλαίσιο γίνεται **bottom-sheet**: σύρε/πάτησε τη λαβή στην κορυφή για να
το ανοίξεις/κλείσεις· ανοίγει αυτόματα όταν υπάρχουν αποτελέσματα.

## Σημειώσεις & περιορισμοί

- **Κοντινοί φορτιστές**: το κουμπί «📍 Κοντινοί φορτιστές» δείχνει τους 6 πλησιέστερους
  στη θέση σου (με τα ενεργά φίλτρα ισχύος), με απόσταση, ισχύ και κατάσταση· για τον
  πλησιέστερο υπολογίζει και την οδική απόσταση/χρόνο. Το «→» σε κάθε εγγραφή σχεδιάζει
  διαδρομή ώς εκεί από τη θέση σου.
- **Ζωντανή θέση**: το κουμπί «◎» (κάτω δεξιά στον χάρτη) ζητά άδεια τοποθεσίας και δείχνει
  το ζωντανό στίγμα σου (με κύκλο ακρίβειας). Το κουμπί «📍 Αφετηρία = η θέση μου» ορίζει
  την αφετηρία της διαδρομής στην τρέχουσα θέση. Απαιτεί **HTTPS** (το Railway το παρέχει).
- **Υπόβαθρα χάρτη**: επιλογέας πάνω δεξιά — Σκούρο / Δρόμοι / **Δορυφόρος** (Esri). Πραγματικά
  πλακίδια Google Maps απαιτούν πληρωμένο Google API key· ο δορυφόρος Esri δίνει αντίστοιχη
  εικόνα χωρίς κλειδί.
- **Geocoding & routing**: όλες οι κλήσεις περνούν από τον server (`/api/geocode`,
  `/api/reverse`, `/api/route`) — ποτέ απευθείας από τον browser. Αν οριστεί
  `LOCATIONIQ_KEY`, χρησιμοποιείται το **LocationIQ** (5.000 αιτήματα/ημέρα δωρεάν,
  εμπορική χρήση με αναφορά, αποθήκευση αποτελεσμάτων επιτρεπτή). Χωρίς κλειδί, γίνεται
  fallback στους δημόσιους **Nominatim/OSRM** (με σωστό User-Agent), που έχουν όρια χρήσης
  και δεν ενδείκνυνται για παραγωγικό φόρτο. Το κλειδί μένει **μόνο στον server**.
  Για self-hosting: `LOCATIONIQ_BASE`, `NOMINATIM_BASE`, `OSRM_BASE`.
- **Υπόβαθρο LocationIQ (προαιρετικό)**: όταν υπάρχει `LOCATIONIQ_KEY`, εμφανίζεται και
  επιλογή υποβάθρου «LocationIQ» στον επιλογέα (server-proxied, κλειδί κρυφό· ρύθμιση
  `LOCATIONIQ_TILE_BASE`). ⚠️ Τα tiles μετράνε στο **ίδιο** ημερήσιο όριο (5.000/ημέρα) και
  η περιήγηση τα ξοδεύει γρήγορα — γι' αυτό **δεν** είναι προεπιλογή· τα δωρεάν CARTO/Esri
  παραμένουν η βάση και το LocationIQ μένει για geocoding/routing.
- **Ισχύς AC**: όταν λείπει το `max_electric_power`, η ισχύς για AC 3-φασικό είναι
  **ενδεικτική** (`3 × V × A`). Για DC (οι κατηγορίες 50/120) χρησιμοποιείται το
  αυθεντικό πεδίο, οπότε τα φίλτρα 50/120 kW είναι αξιόπιστα.
- **Φρεσκάδα δεδομένων**: τα στατικά ανανεώνονται ημερησίως από την πηγή· τα δυναμικά
  (καταστάσεις) κάθε ~10′. Ο server τα ξανακατεβάζει αντίστοιχα.
- **Δομή αρχείου**: το parsing είναι ανθεκτικό — δέχεται είτε καθαρό array, είτε
  `{ data: [...] }` / `{ locations: [...] }`. Αν η πηγή αλλάξει σχήμα, δες το log
  εκκίνησης (`[static] OK — N locations`).
